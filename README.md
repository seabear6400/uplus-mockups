# U-plus 그룹웨어 목업

U-plus 그룹웨어 Task 카드의 **목업(GitHub)** 블록이 렌더하는 공개 목업 저장소예요. 그룹웨어 코드 저장소는 비공개이고, 목업만 여기에 둬요.

## 쓰는 법
1. **기획자**: 외부 파일 없이 한 파일로 된 목업 HTML을 `feature/<기능>` 브랜치의 `mockup/` 아래에 올려요(Claude Code로 만들어도 돼요).
2. 카드 **기획 탭 → `/` → 목업(GitHub)** 에 파일 주소를 붙여요.
   예: `https://github.com/seabear6400/uplus-mockups/blob/feature/filter-save/mockup/filter-save.html`
3. **디자이너**: 카드에서 [스티커]를 켜고 목업 위에 번호 + 메모를 남겨요.
4. **개발자**: 그룹웨어 저장소에서 `node scripts/card-brief.mjs <카드 제목>`으로 목업 위치·스티커·화면설계서를 받아 구현하고, 개발 탭 **목업 ↔ 실연동**에 PR 미리보기 주소를 붙인 뒤 스티커를 [반영]으로 표시해요.
5. 목업을 고쳐 커밋하면 카드에서 [새로고침]으로 바로 봐요.

## 주의
- 공개 저장소예요. 실제 데이터·개인정보·비밀 값은 넣지 마세요.
- 목업은 카드 안 sandbox iframe(스크립트만 허용)에서 실행돼요. CSS·JS는 HTML 안에 넣어 주세요(따로 둔 파일은 안 읽혀요).
